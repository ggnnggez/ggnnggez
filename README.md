### Hi, I'm Nan Gao 👋

I work on agent runtimes: how an LLM agent runs, how it spends its context, and how you can tell whether it did a good job.
Committer on ByteDance's [DeerFlow](https://github.com/bytedance/deer-flow). Before agents, I worked on rendering in a game engine team.

📍 Berlin &nbsp;·&nbsp; 🌐 [nangao.dev](https://nangao.dev) &nbsp;·&nbsp; ✉️ [thunderggnn@gmail.com](mailto:thunderggnn@gmail.com) &nbsp;·&nbsp; [中文](https://github.com/ggnnggez/ggnnggez/blob/main/README.zh-CN.md)

**What I'm interested in**, which is also what I contribute to in [DeerFlow](https://github.com/bytedance/deer-flow):

- **Agent observability and evaluation**: making a run legible, and turning trajectories into signals for improving the harness
- **Extensible harnesses**: stable extension points, so people can build on a runtime without forking it
- **MCP and tool design**: exposing tools and data in a shape models can actually use well
- **Agents in production**: multi-instance deployment, shared state, and IM channels
